# AI and Our Future — seminar deck + presenter view

Bhupendra Sharma · Bhopal School of Social Sciences · 23 Oct 2026

- `index.html`: the slide deck (arrow keys / PageUp / PageDown; N = notes, F = fullscreen).
- `presenter.html`: speaker-notes view for a tablet, synced live with the deck.

Both pages need `?room=<code>` to sync. The video slide links to OpenAI’s “Introducing dots” page.

## iPad setup
1. In Safari open `presenter.html?room=<code>` (the full link with your room code).
2. Share → Add to Home Screen → Add (the icon keeps the room code).
3. Launch from the "AOF Notes" icon: full screen, stays awake, works offline once opened. (Or tap ⛶ Fullscreen in Safari.)
